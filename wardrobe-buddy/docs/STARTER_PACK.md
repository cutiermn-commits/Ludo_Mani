# Wardrobe Buddy — Claude Code starter pack

| File | Purpose |
|---|---|
| `KICKOFF_PROMPT.md` | **Start here.** The first message to paste into Claude Code |
| `CLAUDE.md` | Project memory, loaded by Claude Code every session: rules, stack, workflow |
| `docs/PRODUCT.md` | Problem, users, features, MVP scope, success criteria |
| `docs/UX.md` | The co-designer's sketch turned into screens, themes, tone of voice |
| `docs/ARCHITECTURE.md` | Stack, folders, data model, weather flow |
| `docs/PRIVACY_SAFETY.md` | GDPR + Apple/Google kids' rules as acceptance criteria |
| `docs/OUTFIT_ENGINE.md` | Suggestion rules, scoring, learning (starting values to tune) |
| `docs/ROADMAP.md` | Phases 0–8 with exit criteria |
| `docs/DECISIONS.md` | Decision log + open questions that need you |
| `.claude/skills/*` | Repeatable procedures: kid-safety-review, outfit-engine, release-checklist |
| `.claude/agents/*` | Independent reviewers: privacy-safety-auditor, architecture-reviewer |

Setup: unzip into an empty folder → `git init` → open Claude Code there → paste `KICKOFF_PROMPT.md`.
Keep the photo of the sketch in `docs/sketch.jpeg` locally so Claude Code can look at it too (it is git-ignored, D-041).
